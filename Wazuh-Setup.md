# Wazuh Setup

For the wazuh setup, each scenarios will be using one agent only (either linux or windows) due to limited resources of my current workstation (16GB RAM and 8 Cores CPU). Make sure to check the resources of the device you're gonna be using before setting up the VMs. If you have more than what I have (in terms of resources), feel free to run it in higher specs or run multiple agents in one scenarios.
